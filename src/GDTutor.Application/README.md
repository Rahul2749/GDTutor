# Application boundary

Use cases, explicit DTOs and narrow capability interfaces depend only on Domain and the BCL. Foundation/ now contains an explicitly labelled demonstration service, port and nonpersistent result. The service consumes TimeProvider and its own source interface; there is no DI, Options, ASP.NET, EF or provider-package dependency here.

Real feature services arrive with their authorized leaves. The sample is not a course/student entity or readiness guarantee. See docs/architecture/BACKEND-SERVICES-CONFIGURATION.md for 2.2.2 composition and tests.
