## Result and verification

The [staff/authoring specification](../../design/STAFF-AND-AUTHORING-FLOWS.md) documents the four screens, role matrix, course steps, lesson/reordering interaction, question/equation concept, draft/review/publication states and future-module boundaries. The conversation sample supports local role fixtures, Light/Dark/System and seven condition fixtures. No actual publication, review message, upload or permission change occurs.

| Check | Actual result | Evidence / limitation |
|---|---|---|
| Layout and roles | **929 passing layout observations** across seven widths (320–1440px), both role fixtures/themes, conditions, builder sections and authoring panels | [Browser report](../../design/STAFF-AUTHORING-CHECKS.json); no detected page overflow outside the bounded formula region, visible leaf text below 11px or checked product target height below 44px |
| Authoring/recovery | Search/reset, unsaved Stay/Discard/Save & continue, guarded role change, offline save retention/retry, lesson check/reordering and view-state restoration passed | Real durable drafts, version conflicts and auth APIs not implemented |
| Publication boundaries | Incomplete drafts saved but blocked from publication; unresolved paste blocked readiness; instructor requested review without changing live-version label; admin publication and archive/cancel required their UI checks | Local fixture only, not actual immutable publication/audit records or server permission proof |
| Equation/paste concept | Fraction/power/root subset, visual/source synchronization, unsupported source retained, comparison acknowledgment and invalid-source resolution blocking checked | No general LaTeX parser, rich-text editor, semantic validation or Word clipboard conversion |
| Text rendering | Markup-like prompt remained text in the preview | Narrow prototype assertion, not an application sanitization/security audit |
| Theme/contrast/runtime | System switching at all seven widths; **32 observed text/background pairs met 4.5:1**; zero JavaScript page errors | Default-palette observations, not full accessibility or arbitrary design-edit certification |
| Visual inspection | Representative mobile/desktop/theme course, question, approval, curriculum/equation/paste captures inspected | [20 linked captures](../../design/STAFF-AND-AUTHORING-FLOWS.md#captures-and-verification); full device/zoom/screen-reader coverage remains future work |
| Document/source integrity | Local links/JSON, 89 tracker/roadmap IDs, exact tested-preview checksum and 65 original screenshot hashes checked before handoff | No app build, database, live services or capacity test claimed |

QA refinements included mobile title/status stacking, lesson readiness/edit identity during ordering, synchronized equation values and disabling paste resolution again when the source becomes unsupported. The final source was rechecked before handoff. Host snapshots keep view preferences only; typed draft/feedback content is not persisted there.
