## Result and verification

The [learning/assessment specification](../../design/LEARNING-AND-ASSESSMENT-FLOWS.md) documents lesson context/completion, instructions/eligibility, runner/navigation, saves/conflicts, submission/deadline recovery and release/history rules. The conversation preview provides those four representative screens with review conditions, two fixture sizes and Light/Dark/System appearance. It uses a fixed clock and local simulation, not real video or server operations.

| Check | Actual result | Evidence / limit |
|---|---|---|
| Layout/theme/state coverage | **364 passing layout observations** at seven widths (320–1440px), both themes, all sample conditions plus wide-equation and offline-submit views | [Browser report](../../design/LEARNING-ASSESSMENT-CHECKS.json): no detected page overflow outside the explicit equation scroller, visible leaf text below 11px, product target height below 44px or runtime errors |
| Learning/navigation | Lesson completion retained across sample lesson changes; rules gate, start/resume without another slot, answer/review retention, validated jump to question 250 | Passed at all seven widths. 250 items repeat five templates; no production content/import or backend capacity checked |
| Save/recovery design | Pending submit blocked; conflict preserves unsent draft; retry acknowledges locally; deadline offline stops editing and finalizes only earlier saved answers after status check | Local state simulation; no durability, network conflict reconciliation, server-clock, job or duplicate-finalization proof |
| Scoring/history/release | 3 correct + 1 wrong + 1 blank = **11/20, 55%**; negative score **−1/20** retained; three starts and three history rows; held answers cleared from rendered review | Pure sample arithmetic/DOM behavior, not secure grading/release APIs. Synthetic keys are present in preview code |
| Keyboard/state | Native radio arrow selection retained focus; valid host-state restoration retained attempt drafts/flags, lesson completion and prior sample history | Full accessibility/browser history/security validation remains later |
| Contrast | **32 observed opaque text/background pairs** met 4.5:1 | Default palette states only; not comprehensive accessibility certification |
| Snapshot size | Fully populated 250-question review fixture snapshot: **9,505 bytes**, below 16KiB | Host review state only; not production answer storage |
| Visual inspection | Representative mobile/desktop/theme captures inspected across lesson, instructions, runner and results, including the wide formula and desktop curriculum | [17 linked captures](../../design/LEARNING-AND-ASSESSMENT-FLOWS.md#captures-and-evidence); external video was not loaded |
| Documentation/source integrity | Local links/JSON/tracker IDs, exact tested source checksum and 65 original screenshot hashes checked before handoff | No application build, production API, payment, migration or 500-user test claimed |

The QA pass also checked that normal course expiry allows the illustrated active attempt to continue, while suspension disables editing/submission. These are visible states only; backend eligibility/authorization is not implemented. Curriculum placement, lesson completion memory, radio-focus behavior and host-state restoration were refined and affected checks rerun before handoff.
