## Result and demonstration

See [run instructions and boundaries](../../../experiments/question-editor/README.md). Source lives under `experiments/question-editor/`, separate from the future production app. The preview was recovered on [port 4174](http://127.0.0.1:4174/) after port 4173 was unresponsive. A hidden background process serves the same build; HTTP 200, actual Chrome rendering and equation-dialog opening were verified on 16 October, with zero page errors. Save/reopen stores synthetic draft JSON only in the current browser; it is neither production persistence nor a database model.

Tiptap OSS supplies rich text, a custom atomic node retains each equation's LaTeX/display attribute, MathLive supplies the visual field/templates/keyboard, and KaTeX supplies a candidate preview. The dialog confines the keyboard to its modal layer and restores focus on close. Nine template actions cover fractions, powers, roots, integrals, sums, matrices, vectors, chemistry charges and Greek symbols. Production math schema and full command coverage are not selected here.
