Owner clarified that compactness must come from modals, inputs, buttons, fonts and alignment, not wider outer margins. Restored fluid preview width with 12–24px edge gutters. Shared controls now use 32px desktop height, 13px desktop/body/button text, 15px section/modal titles, label weight 500 and emphasis 600. Touch controls remain 44px and touch fields 16px. Removed sample card eyebrows, simplified tabs to an underline, aligned modal title/Close, reduced dialog/drawer widths to 440/352px and kept paired input baselines aligned. Tablet columns begin at 768px; paired fields wait until 1120px. Palette remains blue/slate with light and neutral charcoal surfaces.

Extended browser coverage to 820/1920px, fluid gutters, field alignment and compact modal geometry; touch tablet portrait/landscape checks exercise both themes and dialog/drawer dismissal. Earlier page-height comparison assets were archived before new captures replaced the shared UI evidence. Page-height reduction is not the acceptance criterion.
