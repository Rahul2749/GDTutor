No .NET project, persistent entity, table, EF mapping, migration, provider SDK or production deployment is included. Database input remains 2.4.1. The isolated editor remains separate and unchanged.

## Result and demonstration

Open the **[frontend preview](http://127.0.0.1:3000/)**. A hidden loopback production server is running for review; it must be restarted if its process/app session ends. The editor's separate preview is not replaced. This leaf intentionally shows a small foundation page, not the final home page or finished theme.

- [App source/run instructions](../../../apps/web/README.md): route groups, feature/shared folders and responsibility notes; strict TypeScript, `@/*`, Next typed routes, lockfile and explicit dev/lint/format/type/build/start scripts.
- Shared import guards prevent representative route/feature dependencies from flowing into shared modules. Reserved groups are readme-only, expose no fake account screens and grant no access.
- Local preview CSS only; no Light/Dark/System implementation claimed. System fonts, no remote media and `noindex,nofollow` metadata for the placeholder; public SEO revisited at 4.7/11.5.
- [Package register](../../reference/FRONTEND-PACKAGES.json), [advisory audit](../../reference/FRONTEND-NPM-AUDIT.json) and [dependency notices](../../../apps/web/THIRD-PARTY-NOTICES.md) record final admission and exclusions.
